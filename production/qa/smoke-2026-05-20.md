### Bugs Fixed During Smoke Check

**BUG-PROTO-001** — Prototype crash on launch (fixed inline, not filed as tracked bug)
- **File**: `prototypes/core-loop-prototype/core_loop_prototype.gd:547`
- **Root cause**: `RabbitSystem.FoodItem` inner class was removed in the sprint-04
  RabbitSystem refactor. The prototype still referenced it via `:=` inference,
  causing a GDScript parse error that prevented the project from loading.
- **Fix**: Replaced `var food := RabbitSystem.FoodItem.new("grass")` and the
  `RabbitSystem.feed_rabbit()` call with a `pass` stub and a comment pointing
  to the production API (`FoodSystem.feed_rabbit(rabbit_id, food_id)`).
- **Impact**: Prototype only — no production code affected.
