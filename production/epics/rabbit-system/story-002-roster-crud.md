## Acceptance Criteria

*From GDD §3.1 and ADR-0001 ownership rules:*

- [ ] `class_name RabbitSystem extends Node` declared in `src/core/rabbit_system.gd`
- [ ] `add_rabbit(data: RabbitData) -> String` assigns a unique `rabbit_id` to `data` (if empty), stores in internal dict and in `GameState.rabbits`, returns the assigned `rabbit_id`
- [ ] `get_rabbit(rabbit_id: String) -> RabbitData` returns the matching instance; returns `null` if not found
- [ ] `get_all_rabbits() -> Array[RabbitData]` returns all currently held rabbits
- [ ] `get_rabbits_in_hutch(hutch_id: String) -> Array[RabbitData]` returns only rabbits whose `hutch_id` matches
- [ ] `remove_rabbit(rabbit_id: String) -> void` removes from internal dict and from `GameState.rabbits`; subsequent `get_rabbit(id)` returns null
- [ ] `rabbit_id` generated by `add_rabbit` is unique (non-empty string; no collision between two consecutive calls)
- [ ] `remove_rabbit` with unknown ID is a no-op — no crash

## Implementation Notes

*Derived from ADR-0001 and ADR-0005:*

```gdscript
class_name RabbitSystem extends Node

var _rabbits: Dictionary = {}  # rabbit_id -> RabbitData

func add_rabbit(data: RabbitData) -> String:
    if data.rabbit_id.is_empty():
        data.rabbit_id = _generate_id()
    _rabbits[data.rabbit_id] = data
    GameState.rabbits.append(data)
    GameState.mark_dirty()
    return data.rabbit_id

func get_rabbit(rabbit_id: String) -> RabbitData:
    return _rabbits.get(rabbit_id, null) as RabbitData

func get_all_rabbits() -> Array[RabbitData]:
    return _rabbits.values() as Array[RabbitData]

func get_rabbits_in_hutch(hutch_id: String) -> Array[RabbitData]:
    var result: Array[RabbitData] = []
    for rabbit: RabbitData in _rabbits.values():
        if rabbit.hutch_id == hutch_id:
            result.append(rabbit)
    return result

func remove_rabbit(rabbit_id: String) -> void:
    if not _rabbits.has(rabbit_id):
        return
    var rabbit: RabbitData = _rabbits[rabbit_id]
    _rabbits.erase(rabbit_id)
    GameState.rabbits.erase(rabbit)
    GameState.mark_dirty()

func _generate_id() -> String:
    return "rabbit_%d_%d" % [Time.get_unix_time_from_system(), randi()]
```

`GameState` is an autoload registered before RabbitSystem — safe to call in any method. Do not call `GameState` in `_ready()` before this is confirmed in project autoload settings.

For unit tests: mock `GameState` via `Engine.register_singleton` (same pattern as EventBus mocking in economy_manager_signal_test.gd).

## QA Test Cases

- **AC-1**: `add_rabbit` returns unique non-empty IDs
  - Given: fresh RabbitSystem; two distinct `RabbitData` instances with empty `rabbit_id`
  - When: `id_a = add_rabbit(data_a)`, `id_b = add_rabbit(data_b)`
  - Then: `id_a != ""`, `id_b != ""`, `id_a != id_b`

- **AC-2**: `get_rabbit` returns correct instance
  - Given: rabbit added via `add_rabbit(data)` returning `id`
  - When: `get_rabbit(id)`
  - Then: returned instance is the same object (identity check)

- **AC-3**: `get_rabbit` returns null for unknown ID
  - Given: fresh RabbitSystem
  - When: `get_rabbit("does-not-exist")`
  - Then: `== null`

- **AC-4**: `remove_rabbit` makes rabbit unfindable
  - Given: rabbit added; `id` recorded
  - When: `remove_rabbit(id)`, then `get_rabbit(id)`
  - Then: `null`; no crash

- **AC-5**: `get_rabbits_in_hutch` filters correctly
  - Given: rabbit A with `hutch_id="hutch-1"`, rabbit B with `hutch_id="hutch-2"` both added
  - When: `get_rabbits_in_hutch("hutch-1")`
  - Then: result contains A only; size == 1

- **AC-6**: `remove_rabbit` with unknown ID is no-op
  - Given: fresh RabbitSystem
  - When: `remove_rabbit("phantom-id")`
  - Then: no error; `get_all_rabbits().size() == 0`
